# VW Sales — Loja de Carros

Projeto acadêmico de uma loja fictícia especializada em veículos Volkswagen, desenvolvido com HTML5 e CSS3.

## Páginas do site
- `index.html` — apresentação da loja e seus benefícios.
- `modelos.html` — catálogo de veículos disponíveis.
- `detalhes.html` — informações e características de um veículo.
- `contato.html` — canais de atendimento e formulário demonstrativo.

## Como acessar localmente
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Utilize o menu superior para navegar pelas quatro páginas.

## Conceitos aplicados
- **Usabilidade:** menu consistente em todas as páginas, botões com textos objetivos, organização por cartões e caminhos claros para voltar ao catálogo.
- **Experiência do usuário (UX):** fluxo da página inicial ao catálogo, do catálogo aos detalhes e dos detalhes ao contato; informações agrupadas para facilitar a decisão.
- **Acessibilidade:** idioma definido como português do Brasil, textos alternativos nas imagens, rótulos associados aos campos do formulário, navegação por teclado, foco visível e link para pular ao conteúdo.
- **Responsividade:** meta viewport, unidades flexíveis, tipografia com `clamp()`, grids e media queries para reorganizar o conteúdo em celulares e tablets.

## Escolhas de design
A paleta em azul-escuro, azul-claro, branco e cinza foi mantida em todas as páginas para criar unidade visual e destacar ações importantes. Os cartões separam as informações dos veículos, enquanto os títulos e chamadas orientam a navegação. O menu permanece consistente para que o usuário saiba onde está e consiga acessar as demais telas.

## Tecnologias

- CSS3

## Publicação no GitHub Pages
1. Envie todos os arquivos para a raiz do repositório no GitHub.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch principal (`main`) e a pasta `/ (root)` e salve.
5. Aguarde a publicação e copie o endereço gerado para esta seção.
